# Morrow 本地 Alpha · 试用指南

这是可在 Windows 本机运行的首版试用程序。它保留个人对话和记忆，可以处理 CSV、创建成果与可复用工具，并在允许后主动联系。它还不能处理任意网站或任意电脑任务；完整界面的自然语言作者仍后置。

## 打开与配置

解压便携 ZIP，双击 `Morrow.cmd`；需要当前用户安装时运行 `Install.cmd`。安装与 DeepSeek 加密凭据需要 PowerShell 7。程序未签名，未注册开机启动，也没有自动更新。发行目录必须完整保留，不要单独复制其中的 EXE。

右下角系统托盘 → 配置 DeepSeek，用户在本地输入自己的 Key，保存后退出并重开。凭据由当前 Windows 用户的 DPAPI 加密；不进入界面代码包、Git 或工具库。不要在聊天里发送 Key。没有配置时仍可查看已有内容和本地数据。

默认数据在 `%LOCALAPPDATA%/Morrow/data`；源码试用原来的数据在 `.product-data`，两者不会自动混合。需要延续源码数据时使用 `tools/start_morrow.ps1 -HomePath <原数据目录>`。新安装不会覆盖旧发布目录。关闭窗口会隐藏到托盘；退出托盘会停止它自己启动的服务。若附着到原有独立服务，菜单会明确写“保留现有服务”。

## 第一段体验

1. 直接说一件事，例如“以后先给结论，再给说明”。左上角“我的 AI”→ 记忆，可以查看、修改、删除记忆或关闭自动记忆。临时对话不读写长期记忆。
2. 附上 CSV，说“按客户汇总金额，核对后给我一份报告”。AI 可以在同一任务里查询、读取结果、必要时修正，再保存文档并答复；临时分析不会自动占用长期工具库。工具卡展开“处理记录”可看每一步的真实状态，“处理思路”是公开摘要，不是模型隐藏思维链。
3. 说“帮我创建一个以后反复用的名单去重工具，CSV 的列叫 name，按 name 去重并升序”。工具保存前会实际执行模型给出的虚构样例。成功后换一份 CSV，说“用刚才的工具处理它”。成果卡下载 ZIP，内含 `result.json`。
4. 左上角“我的 AI”→ 我的工具 → 查看与管理，可以看源码、样例、版本，停用或回退。让 AI 修改的入口会填好工具标识，继续说你的要求即可。样例通过不代表任意输入都一定正确。
5. 主动联系默认关闭。需要时到“我的 AI”→ 主动联系开启、选择范围和勿扰时段；模型选择何时联系并在到期时重新判断。普通聊天不预告时间。明确说“明天几点提醒我…”则创建可见提醒，和主动问候分开。

## 界面自由度

“改变这里”打开独立管理页：导出多文件 JS/TS/CSS 源码包，修改、导入、预览并启用；也可回退。整个聊天、导航和内容布局都可更换，默认界面只是一个实现。

原生桌面支持界面经授权 SDK 改变窗口尺寸、无边框、透明和置顶，可作为桌面伙伴等形态的载体。我们不提供几个固定皮肤让用户挑选。完整“说一句话就由 AI 自动改写整套界面”仍未接通。现阶段只启用自己信任的代码。

找不到按钮时：托盘 → 恢复默认窗口与界面管理，或按 Ctrl+Shift+Backspace。它不依赖自定义界面的按钮。更换窗口边框/透明形态会重载视图，作者应先保存 SDK 草稿；不会重启 AI 服务或重发任务。

## 多步处理、停止与继续

普通聊天不会被强行包装成任务。只有实际调用工具时才显示大的任务卡，包含公开计划、执行记录和可下载成果。失败步骤会保留；如果最后一步工具失败，模型说“完成了”也不会改变实际状态。

处理中可点“停止”。已保存的成果仍保留，停止后的旧回应不会继续触发动作。网络失败没有自动重试；重开程序也不会悄悄重发模型请求。需要时在原任务卡点“从这里继续”，它先读取已有结果；明确停止撤权后的任务应由一条新请求重新授权。

每连续八次模型判断会保存进度并暂停，防止任务持续空转；可以手动继续。单项任务最多 64 次判断，超过后需依据现有成果开始新任务。结果状态不明时先核对，不能把“不确定是否执行过”当成失败后重复执行。

模型每次收到有限结果样本及截断标识，不能据此声称看过完整大表。固定金额核对器使用精确十进制计算；自定义 SQL 查询采用普通数值语义。生成的报告内容仍应结合原数据核对。

## 试用边界

- 私人工具当前是文本/CSV 的只读 SQLite 查询，不能执行生成的 Python、Shell 或任意系统程序。输入最多 2000 行、40 列；结果最多 1000 行。复杂数据应分批处理。
- 金额精确核对继续使用原 CSV 核对器；SQL 自定义工具采用 SQLite 的常规数值语义，不承诺十进制财务精度。
- 主动联系与提醒需要电脑和本地服务运行。关机时不会在云端继续工作；Windows 通知还取决于系统状态，持久消息以产品“近况”为准。
- `/code` 是可选官方编码 CLI 适配，默认不开启；真实 CLI 连通未验收。TTS、社区分享、云端常驻及通用 Computer Use 不属于当前 Alpha。
- Electron 开启渲染器沙箱、上下文隔离、窄 IPC 和外网请求限制；这些是防护措施，并不表示已经审计成可运行任意敌对社区代码的通用安全沙箱。
- 首版经过本机验证，尚未完成另一台电脑的安装、长时间睡眠唤醒及系统通知送达验收。
