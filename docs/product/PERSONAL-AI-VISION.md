# Personal AI · 产品定位 v1.1

来源：用户在 BATCH-010 独立复核后提出的最终商业理念。本文是后续产品取舍的方向依据，不是已实现功能清单，不把愿景视为已经获得用户验证的商业事实。

## 核心承诺

一个真正属于个人、长期陪伴用户、理解用户，并能够在得到授权的现实任务中帮助用户做事的 Personal AI。用户不必学习如何配置 Agent；AI 应逐渐学会怎样成为这个人的 AI。

用户可以通过自然语言改变说话方式、外观、布局、工作习惯和可用能力：

- “以后说话直接一点。”
- “这个界面我不喜欢，换一种。”
- “每天晚上帮我总结今天的工作。”
- “以后这种事情你直接帮我做。”

不同请求对应不同变更。调整语气不增加权限；更换外观不清空记忆；安排日程要明确来源、时区和范围；授予长期自动执行权限要明确动作、资源、期限和费用边界。用户不需要理解这些内部机制，但产品必须正确执行。

## 陪伴来自共同经历与实际帮助

Memory 让 AI 记得用户；Awareness 让它注意到获得授权的上下文与变化；Agency 让它采取有用的行动。共同完成的工作、用户纠正、逐渐形成的偏好与工具，构成持续的关系。

“关心不仅是一种语言，更是一种行动。”只能说“已完成”的事情必须有实际成果或回执；没有观察到的活动不能编造成“我注意到你一直在……”。不把占用用户更多时间、制造依赖或冒充人的情感当作成功指标。

底层模型、工具和 Coding Agent 是可演进的基础设施。用户可以在详情中查看真实执行来源与费用，但通常感知到的是一个连续的主体：“我的 AI 帮我完成了这件事。”

## 成长包括界面本身

个性化的主要方式是用户向自己的AI描述想法，由AI编写或修改代码，直接形成新的界面、交互或能力。可以从极简入口变成角色空间、研究桌面或自用的小应用集合；不要求先在产品提供的几种主题、布局或组件组合中选择。

产品提供便于生成、预览、验证、装载、替换和恢复的基础设施，以及清晰的接口和可编辑源码。AI可以自己实现，也可以调用已有Coding Agent；已有库和组件供它按需复用，不限定它的表达空间。我们不以预设数量、主题选择器或低代码搭建器作为个性化能力。

用户可直接提出定制，也可选择社区作品作为起点，再让AI继续改成自己的版本。社区复用是可选入口，离开社区也必须能完成定制。默认只有一个足够简洁的起始界面和可靠的恢复界面，无需维护多套供用户挑选的官方皮肤。

相同原则适用于可替换的角色呈现、交互方式、Skill和小工具：围绕稳定接口生成或改造实现，验证后替换；人格与偏好可以修改结构化配置或指令，不为每次改语气强制编写程序。

允许变化的包括表达方式、视觉风格、布局、角色呈现、技能组合和工作方式。身份归属、授权、费用、私人资料保护、真实执行状态和可恢复性由产品基础机制保证，不能随一次改版消失。

## 分享与 Fork

用户可以展示自己定制的界面、自己选择公开的人格设定、通用 Skill 和生成的小工具。可分享作品的源码和适用接口，让别人借鉴、Fork并继续修改；新实例具有自己的身份与独立授权。私人记忆、聊天、任务记录、客户资料和连接凭据不随作品传播。

分享内容是“我愿意公开的样子与能力”。预览使用虚构资料；有意公开个人文字、头像或素材须单独选入。社区作品的后续更新也不得静默覆盖 Fork 的个人修改。

传播假设：显著的外观差异提供第一眼吸引力；真正省事的能力提供持续使用理由。是否成立要通过用户保留改版、主动分享、他人成功采用和实际重复使用来验证，不预设必然病毒式增长。

## 体验定位

默认是一个简洁的个人空间：一个伙伴入口、一句话输入、少量确实值得出现的近况。任务进度、成果和判断卡片按需出现。表格、来源、历史、授权详情属于可展开的工作区域。

当前 CSV/JSON 工作台是技术验证和一种工作视图，不是最终首页，也不意味着产品以表格为核心。用户不必知道 snapshot、manifest、JSON、任务编号或校验哈希。

## 首个需要证明的体验

用户说“把这里改成一个安静的阅读空间，内容像便签一样展开，说话直接些” → AI修改当前实现并完成预览和替换 → 用户继续说“再把右边留白加大”并得到增量修改 → 用户交给它一个真实的小任务 → 它完成并呈现可核对的结果 → 用户愿意保留这个版本，并能分享一个不带私人资料、仍可继续编辑的作品。

这证明“我的 AI 因我而改变，而且能帮我做事”。完整长期记忆、能力生成、日程与现实连接分步接入，不能靠演示动画冒充实现。

产品表达：

> The AI that builds itself around you.

> Your AI already knows you. We give it hands.

前一句适合整体定位；后一句更适合有既有记忆或明确迁移入口的场景。面向新用户应承诺“逐渐理解你”，不能暗示自动知道其他平台中的私人历史。

用户最终希望表达：**“这是我的 AI。”**
