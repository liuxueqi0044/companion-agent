# Morrow · 邀请试用

这是 Windows x64 邀请测试版。FORM 和 ATELIER 是两个可以继续修改的完整界面，共用聊天、记忆、工具和目标模式。这个包不含社区鲸鱼娘图片、精灵图或其编码后的源码。

## 第一次打开

1. 解压整个 ZIP，双击 `Morrow.cmd`。也可先运行 `Install.cmd` 安装到当前用户目录；开始菜单会添加 Morrow，在 Windows 已安装应用中可找到对应版本。
2. 首次提示中选择连接 DeepSeek，在本机输入自己的 API Key；保存后从托盘退出并重新打开。以后可通过系统托盘 → 配置 DeepSeek 修改。也可先不配置，浏览界面。
3. 发一句“你好，以后回答简短一点”。再使用一份不含私人资料的 CSV，尝试“按 name 汇总 qty”。
4. 左上角空间名称可切换 FORM / ATELIER；右上角空间菜单管理记忆、工具与近况。

记忆默认开启，可查看、编辑、删除或关闭；临时对话不读写长期记忆。主动联系默认关闭，开启后才由模型安排联系时机。提醒和主动联系都依赖这台电脑及本地服务运行，关机后不会在云端继续。

## 数据与模型

对话、记忆和成果保存在 `%LOCALAPPDATA%\Morrow\data`，API Key 加密保存在当前 Windows 用户的 `%LOCALAPPDATA%\CompanionAgent\credentials`。DPAPI 凭据不能直接当作跨电脑备份使用。

连接 DeepSeek 后，当前请求、相关对话、记忆和所需附件内容会发送到 DeepSeek，用你自己的 API 账户结算；这不是完全离线产品。测试前先用虚构材料。程序不会自动将对话或诊断上传给项目开发者。不要在聊天或问题反馈中贴 API Key。

## 退出、更新和卸载

关闭窗口会隐藏到系统托盘；需要停止本应用自己的后台服务时，从托盘退出。如果桌面连接的是已有服务，退出菜单会标明保留服务。

更新前退出旧版本，保留一份数据目录备份，再安装新版本。版本安装目录相互独立；使用同一数据目录会保留已有内容。不要让不同版本同时写入同一数据目录。没有自动更新。

卸载前退出程序，然后在 Windows 已安装应用中卸载，或运行安装目录内 `Uninstall.cmd`。卸载只删除对应版本发行文件，保留对话、记忆、成果和凭据。修改过的发行文件会导致卸载停止，其他未知文件会保留。便携解压目录没有安装登记，退出后可自行删除程序目录；它与个人数据目录分开。

## 遇到问题

- 双击 `Check.cmd` 可运行离线环境检查：不读取 API Key，不调用模型，使用全新测试数据，保留检查报告。
- 系统托盘 → 导出脱敏诊断，生成 JSON 后自行查看并发给邀请人。它包含版本、连接状态和有限错误码，不含对话、记忆、附件、绝对路径或凭据，也不会自动上传。
- 报告问题时补充：做了什么、预期发生什么、实际发生什么、能否重复。截图先遮盖私人内容。
- 系统托盘 → 测试系统通知，可检查通知是否可见。系统可能抑制弹窗，实际消息以应用近况为准。
- 界面不可用时按 `Ctrl+Shift+Backspace`，或托盘 → 恢复默认窗口与界面管理。

## 当前边界

可用：持久聊天、记忆、主动联系、有限 CSV / SQLite 工具、目标拆分和验收、本机已安装 Claude Code 的有限文件编码。Claude Code 不随包安装；普通聊天和 CSV 不依赖它。

未提供：任意程序执行、通用电脑操作、TTS、云端常驻、社区下载，以及一句话自动改写整套界面。可以导出、修改、预览和启用完整 UI 源码；只启用自己信任的代码。
