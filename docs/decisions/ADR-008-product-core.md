# ADR-008 · 个人AI应用核心与自然主动联系

2026-09-24，独立架构师开发目录中的实现决策，等待后续集成复核。原项目BATCH-016-R2、历史报告和accepted计数不变。

## 复用和新增

保留services/personal_ai的身份/偏好、services/local_tasks的SQLite任务/Decimal工具/进程锁、原有个人空间代码包封存协议。新增services/product应用层：交互记录、模型建议接纳、受控动作、管理记忆、主动策略与持久收件箱。Node只提供固定stdio宿主端口，不另建通用Agent规划循环或公共HTTP服务。

三个SQLite文件分别是身份、任务、产品运行记录的权威。没有跨库原子事务承诺。先持久化稳定action_id，然后调用原服务的幂等command_id，再存回执。进程在业务已提交、产品日志未提交之间崩溃时，显式重放原命令恢复；不得换新ID重复交办。测试包括真正的子进程硬退出。

## 记忆归属的明确阶段变化

原ADR-002指向Hermes/MemoryPort，但当前没有已运行的Hermes记忆后端。此轮新增唯一的ManagedMemory/MemoryPort本地实现，复用标准SQLite保存少量带来源记录，供首版用户查改关删。不添加向量库，不同时双写Hermes或另一个语义系统。

这是一项显式适配决策：将来接通Hermes时，需要选定唯一后端并迁移，测试删除和关闭传播后切换；不能在两个后端各存一份“真实记忆”。自动提取来自ModelPort的结构化建议，离线脚本不证明语义质量。显式名称/语气继续由原profile服务保存。

记忆默认开；关闭阻断后续检索与新提取。生成票据绑定策略修订，开关/删除在生成期间变化会拒绝旧输出。忘记保存来源排除标记，阻止同一来源进入后续历史提取。当前保守地取消可能依赖旧记忆的所有未发自动联系；以后有可靠的细粒度依赖后再缩小影响。

## 主动联系的产品规则

默认关。用户开启后，模型决定是否跟进、何时跟进以及表达；应用只检查用户允许的时段/话题、频率、生成预算和有效期。自动计划不进入普通聊天、首页、通知预告或默认设置返回值。显式定时提醒照常确认。内部计划仅由诊断/用户主动要求的管理入口读取；已送消息可查原因。

保存意图，到期再调用模型复核。真正投递前再次检查规则版本、最近会话变化、时效、安静时段和当日额度。关掉功能、撤销来源或屏蔽话题能使旧生成票据失效。消息插入和计划完成在同一事务，重试不重复消息。未回复不生成新的追问链。

每次自动计划最多七天；默认一天最多一条自动消息、最多三次到期模型复核，两个额度分别可配置。失败/进程中断标needs_retry，必须显式重试，不在后台无限花费。tick是本地宿主调用的有界入口，尚无系统常驻服务；本轮没有创建真实系统定时任务。

Windows现有运行环境未安装IANA时区数据。UTC和明确UTC±HH:MM由标准库支持；命名时区仅在zoneinfo数据实际可用时接纳。不把固定偏移假装成带夏令时的城市时区。

## 模型、宿主与界面

ModelDecision只有回复和有限建议，不能声明权限、修改策略或给任务写completed。权限由可信宿主提交交互时给出，当前只有csv.audit和profile.change；未提供则为空。单个模型输出不允许任意shell、路径、网络或陌生工具。

供应商公开摘要通过可信适配器的ProviderReply元数据单独进入，不允许模型在自身生成的JSON里冒充供应商摘要。未配置模型显示真实不可用，不伪装成语义对话。线上适配器、流式摘要和真实语义试验继续单列。

经验版本引用使用已有代码包格式。只登记经过宿主明确审阅的源码/产物双hash配对；source_type标记不能独自授予可信地位。启用/回退做CAS，保留同一身份与任务。当前是版本登记和状态连续性，真实DOM替换、输入迁移和Electron隔离尚未集成；model_candidate继续拒绝激活。

Node的固定进程配置和Python应用对象都是可信宿主专用接口。它们不是给生成页面或公网调用的权限边界。后续Electron main/preload仍需来源认证和窄IPC；生成页面不得直接拿到request方法、turn.accept或策略修改能力。
