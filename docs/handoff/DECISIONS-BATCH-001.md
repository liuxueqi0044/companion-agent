# BATCH-001 架构裁定

状态：架构负责人为当前 M00.1 文档与样本批次作出的确定结论。用于消除产品描述歧义，不修改 C01–C11、TaskBrief 或公共端口；M00.6 仍负责实现契约冻结。

## D1：任务身份

- S5 换一份需求和 CSV，创建新 task_id、业务幂等键和初始 attempt，固定使用某个 capability version/package_hash。可在 UI 归到同一会话；会话不等于任务。
- 同一业务任务的失败重试/中断恢复才创建新 attempt，旧输入与结果不覆盖。网络重发同一业务请求沿用原幂等键，不创建重复任务。
- S2 在 waiting_user 中补充/纠正输入可继续当前任务，不把每次输入都强制定义成一次重试；需要重新执行时由服务协调 attempt。本文只定义可见行为，不补造新的 API 字段。

## D2：保存与启用

- 用户接受保存提议只授权制作可复用候选包。内部必须经历 draft → testing → ready；独立验证通过且 package_hash 与拟发布版本一致、发布授权覆盖准确版本及权限时，才允许切 active 指针。没有覆盖该版本的授权时应请求确认。可把这些过程放进同一个 S4，不增加第二条用户链路。
- 验证失败或缺授权：展示候选状态/失败原因，可修改或取消，不作为已启用功能供 S5 使用。拒绝保存保留本次工作结果，不产生启用功能。
- 载体沿用 SKILL.md + scripts + capability.json 的不可变版本包，注册表保存元数据和 active 指针；Hermes 在授权范围内使用固定版本。不把工作区中的普通规则文本当成权威发布状态。物理存储位置由后续已有技能模块任务实现，此处不发明新目录/API。
- 停用阻止后续自动选用该版本，不删除历史结果/规则来源，不等价于取消正在执行的任务；取消按 C03 单独处理。

## D3：首版字段

沿用 first-flow 第 4 节最小字段，不增加税率计算、汇率转换、交期格式引擎。所有金额的币种和含税口径必须来自明确输入或用户确认，不能硬编码地域默认值。为了定义可人工核对的期望，fixture 可有内部字段名、来源引用与 null 状态；它们不是新的公共接口契约。

保存可复用的处理规则，不复制上次客户资料或金额到新输入。显式新输入与规则冲突时列出问题，不静默覆盖输入。样本须区分“这次纠正的字段值”和“用户确认以后复用的规则”。

## D4：金额、来源与缺失

- 允许由明确的 quantity × unit_price 得到行小计，并对同一已知币种的完整明细求和；金额使用十进制定点语义。小样本选取无需舍入争论的数据，不引入货币精度服务。
- 计算结果的来源要记录公式和操作数字段引用；在输入、用户确认、待确认之外补充“确定性计算”的成果卡标记。没有来源的金额不能因为模型有把握就输出。
- 数量/单价/币种等必要信息未知时，小计或完整合计保持 null/待确认，已知为 0 与未知 null 分开。可以显示已知部分，但必须标成部分小计，不能冒充完整合计。
- 混合币种不相加为一个总额；首版可分别显示已有行小计并提示无法给出单币种完整合计，不实现自动换汇。缺列、空值、冲突都有明确问题。未知执行费用同样是 null。

## D5：对外发送

排除的是客户邮件、聊天消息、CRM/ERP 写入、网页表单提交、下单、支付、报价承诺等对外业务动作。用户授权的模型推理、对象存储和沙箱属于基础设施，但仍受 permission_grant、allowed_connections、cloud_fallback_allowed、数据范围及预算约束；不能以“基础设施”名义越过授权上传文件。没有云端授权不得自动回退云端。

本批仅做本地文档/虚构 JSON 样本，不需要也不授权实际云端模型、账号、支付或沙箱调用。

## D6：保留样本的诚实边界

M00.1.03 的 holdout.json 只放预留输入，不含预期答案；expected.json 仅含 normal/missing 的公开期望。纠正案例可公开，因为它属于开发样例。

开发者制作且看过的 holdout 只能称“预留验收输入”，不能声称对该开发者真正未见。后续代码生成不应加载该文件，也不把它当演示/训练示例。独立验收者在本批提交后生成并保管其预期结果，正式运行验收再补充未暴露的新输入。本地目录约定不是强安全隔离。

本批交付的是输入与验收规范，开发者不能伪称已经完成独立盲测或真实产品复用。报告注明 evaluator_followups（待独立验收者给 holdout 定义预期），不可自行写 reviews/。独立复核完成该验收方工作后才能接受对应卡。
