# CORE-007 · 首个可操作的个人空间

2026-09-24，架构师执行。用户已调整视觉推理档位，并明确允许使用既有 DeepSeek API 密钥。

## 目标与边界

复用 CORE-006 runtime，不重写业务、任务或记忆存储。交付温暖克制的默认个人空间，以及与真实本地服务相连的对话、CSV 成果、记忆控制、收件箱和主动联系设置。默认空间是未来可被代码替换的一个实现，不建立官方多模板系统。

本批是本机浏览器产品试用入口，不声称 Electron 原生沙箱、生成 UI 安全执行或安装包已经完成。生成候选不装载。默认不开后台 pulse；主动联系策略先可真实配置。由既有服务保证默认记忆开、主动联系关，普通对话不预告自主联系时间。

## 实现分层

1. apps/desktop/product/providers/deepseek.mjs：可信注入凭据、固定官方端点、JSON 输出、请求取消、限长、错误净化。共用串行请求与持久六次尝试预算；不输出隐藏推理，不保存原始响应；调用前占用额度，失败不自动重试。
2. apps/desktop/product/web/：只监听 127.0.0.1 的试用宿主；随机会话令牌、精确 Host/Origin、固定静态资源表、白名单操作，无任意文件/命令/host.request。运行时快照带单调修订，操作与纯读取分离；多标签页导航/选中写入要明确校验。
3. apps/desktop/personal-space/：复用 Vue 3 本地运行时，手写渲染函数与原创 CSS，数据用文本渲染。首页、对话、较大的任务区、记忆/近况/联系面板、CSV 材料与结果。未连接、未知、取消、错误不伪装成功。
4. tools/personal_space.mjs + 启动 PowerShell：固定可信配置，当前账户 DPAPI 在子进程内解密，密钥只在服务端内存；启动输出只含本地地址与非敏感状态。关闭等 runtime.whenIdle 后再释放 host。
5. tests/product/core007/：离线 provider、预算、HTTP 权限、视图版本与实际本地组合；真实 API 小样与浏览器体验单列证据。

## 验收

- 主页/设置/刷新不会调用模型；首次视觉无需数据种子，无假消息或假任务。
- 同一输入 ID 不重放生成；上传文件仅提供 CSV 文本，路径不传后端；模型动作只能使用可信授予的有限能力。
- 真正发送可得到 DeepSeek 回复；一条 CSV 工作经 Node→Python→SQLite→worker 完成并可查成果来源。
- 用户可控制记忆、编辑/忘记条目，主动联系默认关且可保存设置；未运行后台调度明确说明。
- 远程 Origin、错误令牌/Host、泛化动作、路径穿越被拒绝，凭据不出现在响应/静态资源/报告。
- 桌面与窄屏实看，键盘/加载/断连/错误/取消可处理；最后报告完成与 not_run。

真实调用新额度最多 6 次，包含验证与本机页面试用；共享持久账本，不用历史 BATCH-012 额度。仅使用虚构测试文本做研发验证，不发送历史私人记忆；不通过 OpenAI 发起附加请求，不创建子代理/会话。
