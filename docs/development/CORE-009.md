# CORE-009：连续输出与连接恢复

## 产品行为

普通聊天从“正在思考”开始，公开处理摘要和回复随后逐步出现。当前输出标为生成中；真实工具卡独立展示执行步骤、完成回执和来源。模型输出未完整结束或格式校验失败时，部分文字不会被当作最终结果保存，更不会执行里面的动作、写记忆或安排联系。

页面使用经过同源与会话校验的事件流。断线重连读取最新累积输出和真实状态，不重发 send、不再调用一次模型。页面刷新可接回宿主当前选择的对话；非临时对话只在 localStorage 记住选择 ID，正文仍由可信宿主管理。服务重启后更换会话令牌与 epoch，旧响应不能覆盖新状态；自动恢复选择仅发只读打开命令。

## 模块与边界

- `personal-space/sse.mjs`：共享 UTF-8 / SSE 帧解码器，处理拆包、换行、终止、取消和大小边界。复用原生 ReadableStream，不引入新依赖。
- `product/providers/streaming.mjs`：DeepSeek 完整流解码和公开字段投影。仅投影顶层 reply / displayable_summary，不投影工具参数、记忆、联系计划和私有 reasoning_content。正确 stop 与 DONE 均收到后才进入最终输出验证。拒绝重复顶层字段、截断、混合 choice、换 stream id 和异常类型。
- `product/providers/deepseek.mjs`：产品启动显式开启 streaming，旧非流式接口保留作实验兼容。进度含 turnId / runId；失败清除预览。凭据回显检查在原始与解码内容上执行，半截公开字符串保留凭据长度的尾部，避免分片泄露。
- `product/web/server.mjs`：同源、CSRF 会话保护的 POST `/api/events`。运行时和适配器共同推动快照修订号，35 ms 合并更新；慢连接有背压，15 秒心跳发送可验证快照。
- `personal-space/client.mjs`：重连只恢复读取通道，35 秒无事件则重新连接；服务重启只刷新本地会话，不自动重放任何写命令。会话代次过滤迟到回执。
- `personal-space/activity.mjs` 与 `app.mjs`：公开草稿与最终回复分开；当前真实 worker 回执优先于尚未刷新的对话记录。旧 turn、不再运行的 turn、取消和失败均不能显示迟到草稿。

Python 产品内核、冻结 CORE-006 十项文件、原 companion-agent 开发目录和所有历史报告均未修改。没有安装依赖、启动额外智能体会话或调用 OpenAI 账号。

协议实现核对了 DeepSeek 官方 [Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion/) 与 [JSON Output](https://api-docs.deepseek.com/guides/json_mode/)，检查日期 2026-09-24。

## 验证

整套 Node 回归 222 项通过；最后的连接心跳、会话代次与错误映射修订另有 43 项定向通过（包含新增反例，不把两组简单相加）。Schema / 原始依赖快照检查通过。真实本地 Node→Python→SQLite→CSV 流式演示产出 16.00 USD；半截 JSON、停止、中断和重连均不重复执行。

两次真实串行 DeepSeek 临时对话均 HTTP 200，没有自动重试。传输观察分别收到 31 / 57 个快照和 20 / 47 种部分回复长度。浏览器观察到未完成的回复和公开思路；完成后刷新仍能查看同一条回复。生成中断线恢复由隔离的真实本地 HTTP 流测试覆盖，不将完成后的浏览器刷新冒充生成中刷新验收。服务闲置重启后浏览器自动恢复原选中对话，调用账本未变化。

## 未完成与下一阶段

当前可交付本机试用版本，整体产品仍不接近发布收尾。重要缺口如下：

1. 自由代码改版：原工作区已有三文件包、静态审查、窄桥和恢复试验；下一阶段把它们接入实际个人空间，实现提要求 → 写代码 → 隔离预览 → 启用 → 回退，保留身份、记忆与任务。尚未允许未经隔离的生成代码进入当前可信页面。
2. 主动联系后台：复用已有协调器，完成进程生命周期、免打扰、过期复核、去重与应用内送达。默认关闭；开启后由模型决定内容/时间，不提前宣布问候时间。
3. 桌面和分发：可移植依赖、安装与升级、原生隔离、受控文件/系统工具；当前仍是 localhost 浏览器试用，不是完整 Electron 产品。
4. Coding Agent / Skills / 分享：官方执行器真实接入、能力包复用、导出 Fork 与私人数据分离。TTS 和角色表现安排在真实帮助与自由改版闭环之后。

读取通道重连不等于重放失败的任务。模型执行进程崩溃、未确认的请求账本和有外部副作用的未知结果仍须核对；不能通过清空 reserved 记录自动再调用模型。
