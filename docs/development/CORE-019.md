# CORE-019 · Invitation Alpha delivery

Goal: make a small Windows invitation trial reviewable, without claiming cross-machine or public-release readiness.

1. **Distribution profile.** Keep the local whale prototype; build a separate invitation artifact containing only FORM / ATELIER. Exclude character bytes from every file and source export. Reuse the existing shared runtime and immutable package store. Acceptance: both interfaces build from the copied release; unavailable starters fail closed; manifest/ZIP inspection finds no character assets.
2. **Installation lifecycle.** Reuse verified manifest installation. Add a per-install receipt, current-user app registration and an uninstaller which validates paths, refuses running/modified releases, removes only inventoried files, and retains unknown files and all personal data. Acceptance: actual Windows install/uninstall in fresh test roots, tamper/path rejection, preservation of unrelated files.
3. **First use and support.** A small trusted native welcome explains local storage, API requests, memory and proactive defaults. Keep the minimal existing UI. Add tray help and explicit local diagnostic export built from an allowlist, never raw logs, conversations, paths or credentials. No automatic uploads. Acceptance: sensitive-marker regression and native smoke.
4. **Background delivery.** Persist native notification consumption to avoid duplicate toasts; wake rechecks through the existing single-flight scheduler. Verify restart/pause/failure boundaries. Distinguish synthetic wake tests and OS notification submission from actual physical sleep/wake and human-observed delivery.
5. **Copied-release checks.** New packaged offline integration, native checks, and one serial DeepSeek trial using fictional inputs and the existing encrypted key. No OpenAI account calls, extra assistant sessions, automatic provider retries or real-user-data writes. Keep failures and prior reports. Generate invitation guide, manual cross-machine checklist and report with remaining external checks.

No certificate purchase, public publication, startup registration, global security changes or real user reboot/sleep. A second computer and signing identity remain external inputs. Whole-interface natural-language authoring stays deferred.
