# M03 · 主控 Agent 与长期任务

原生客户端→运行映射→模型分工→继续/恢复→验收

## 模块内部结构

SupervisorRuntime 包装 Hermes；事件翻译器不执行事件里的工具。任务服务保留权威产品映射。模型决定步骤，代码控制预算和完成条件。

## 责任边界

普通 delegate_task 的可配能力按已验证版本；不得虚构每任务模型参数。恢复先查存活/副作用，重试新建 attempt。

归属范围：`adapters/hermes`, `services/control/runtime`。实际写权限进一步受单张任务卡限制。

## 输入输出与验收

复用强模型规划、委派和验收能力，保证产品状态真实。

输入由契约和上游已验收产物提供；输出经本模块公开接口交给下游，不越层读取供应商内部状态。优先局部测试，再在父任务最后的真实场景验证集成。
