# M11 · 测试、观测、部署与发布

契约测试→CI→观测→恢复/发布证据→产品决策

## 模块内部结构

此模块从基础工程开始，不是上线前才介入。测试用可复现输入与真实证据，不以 mock 成功替代外部集成。

- [C10 计量、预算和账单](../contracts/C10.md)

## 责任边界

变更检查需扣除任务开始前已有改动；审核者不能只读自评。发布结论不等于授权执行生产发布或对外发消息。

归属范围：`tests`, `infra`, `services/control/observability`。实际写权限进一步受单张任务卡限制。

## 输入输出与验收

从第一个接口起建立可诊断、可回退的交付过程。

输入由契约和上游已验收产物提供；输出经本模块公开接口交给下游，不越层读取供应商内部状态。优先局部测试，再在父任务最后的真实场景验证集成。
