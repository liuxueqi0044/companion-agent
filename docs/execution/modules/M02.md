# M02 · 身份、数据与产品控制服务

身份→归属存储→队列/事件→运行单元

## 模块内部结构

API 验证主体，应用服务校验资源归属，repository 负责事务。outbox 保证记录与待投递意图同事务；queue 是传输，不是第二套规划器。

## 责任边界

数据库变更以不可变新迁移提交；不能修改已应用迁移。任务 attempt 与原生 run 绑定防重复启动，但外部副作用另行核对。

归属范围：`services/control/identity`, `services/control/tasks`, `infra/database`。实际写权限进一步受单张任务卡限制。

## 输入输出与验收

提供可靠的多用户任务入口和持久产品状态。

输入由契约和上游已验收产物提供；输出经本模块公开接口交给下游，不越层读取供应商内部状态。优先局部测试，再在父任务最后的真实场景验证集成。
