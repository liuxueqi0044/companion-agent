# M01 · 产品体验与桌面界面

状态组件→桌面壳→API 客户端→任务/成果/功能页

## 模块内部结构

页面只消费快照和事件。数据请求在 api 层，归并在 state 层，组件不调用供应商 SDK。main/preload 是本机权限边界，renderer 是非可信展示层。

## 共享接口

- [C02 任务与产品 API](../contracts/C02.md)
- [C03 生命周期与事件](../contracts/C03.md)
- [C06 成果与存储](../contracts/C06.md)

## 责任边界

不能用 UI 状态推断实际执行完成；不能让生成 HTML 获得主窗口权限。静态视觉修改用人工走查，不写只复述实现的测试。

归属范围：`apps/desktop/renderer`, `packages/ui`, `apps/desktop/main`。实际写权限进一步受单张任务卡限制。

## 输入输出与验收

让用户自然地聊天、看成果、重复使用功能。

输入由契约和上游已验收产物提供；输出经本模块公开接口交给下游，不越层读取供应商内部状态。优先局部测试，再在父任务最后的真实场景验证集成。
