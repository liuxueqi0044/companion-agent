# M10 · 成本、额度与商业化

计量→预留/结算→付款规则→套餐/权益→指标

## 模块内部结构

用量账本 append-only，以回执幂等；预算使用事务。支付适配器只管理本产品服务权益，不把官方 Agent 额度当自有可转售库存。

## 共享接口

- [C10 计量、预算和账单](../contracts/C10.md)
- [C01 身份、资源与错误](../contracts/C01.md)

## 责任边界

unknown 与 0 严格分开；跨币种不能直接加。供应商和市场选择不足时留专门架构决策，测试不能真实扣款。

归属范围：`services/control/usage`, `services/control/billing`。实际写权限进一步受单张任务卡限制。

## 输入输出与验收

让每次任务的费用有归属，让产品能测出真实毛利。

输入由契约和上游已验收产物提供；输出经本模块公开接口交给下游，不越层读取供应商内部状态。优先局部测试，再在父任务最后的真实场景验证集成。
