# M05 · 工具、沙箱与成果

工具登记→授权账本→沙箱→成果→文本/CSV

## 模块内部结构

ToolGateway 验证后才执行；SandboxPort 只承载任务代码。ArtifactStore 校验实际内容再发事件；预览策略不执行文件本身。

## 共享接口

- [C05 工具、权限与外部动作](../contracts/C05.md)
- [C06 成果与存储](../contracts/C06.md)
- [C10 计量、预算和账单](../contracts/C10.md)

## 责任边界

允许的输入不等于允许任意宿主命令。沙箱清理须以产品标签和资源记录核对；不能为了测试删除无关云资源。

归属范围：`integrations/tools`, `services/control/permissions`, `services/control/artifacts`。实际写权限进一步受单张任务卡限制。

## 输入输出与验收

提供可复用执行工具和可信成果交接。

输入由契约和上游已验收产物提供；输出经本模块公开接口交给下游，不越层读取供应商内部状态。优先局部测试，再在父任务最后的真实场景验证集成。
