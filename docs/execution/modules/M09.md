# M09 · 语音与角色表现

按住录音→转写确认→短 TTS→可选实时管线

## 模块内部结构

语音管线共享既有主会话和任务权限。采集/识别/合成/播放分开，取消各自释放资源。

## 共享接口

- [C11 语音通道](../contracts/C11.md)
- [C10 计量、预算和账单](../contracts/C10.md)

## 责任边界

P2 默认暂缓；真实需求与语言质量验证后再开工。不默认持续录音，不引入第二套 Agent 核心。

归属范围：`integrations/voice`, `apps/desktop/renderer/voice`, `apps/desktop/renderer/companion`。实际写权限进一步受单张任务卡限制。

## 输入输出与验收

在工作价值成立后增加自然表达和演示吸引力。

输入由契约和上游已验收产物提供；输出经本模块公开接口交给下游，不越层读取供应商内部状态。优先局部测试，再在父任务最后的真实场景验证集成。
