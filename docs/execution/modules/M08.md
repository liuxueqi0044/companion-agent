# M08 · 主动消息与调度

偏好→纯策略→Hermes job→收件箱→投递/反馈

## 模块内部结构

调度只产候选，纯策略先决定是否值得发，再必要时组织语言。消息持久化先于桌面通知；反馈影响下次候选。

## 共享接口

- [C07 记忆和工作记录](../contracts/C07.md)
- [C09 调度、收件箱和消息](../contracts/C09.md)

## 责任边界

安静时段按用户时区，考虑跨午夜/夏令时；不能把本机通知送达当已读，不能在缓存中创建第二套调度定义。

归属范围：`services/control/notifications`, `adapters/hermes/jobs.py`。实际写权限进一步受单张任务卡限制。

## 输入输出与验收

让伙伴在有价值的时刻主动出现，而且容易控制。

输入由契约和上游已验收产物提供；输出经本模块公开接口交给下游，不越层读取供应商内部状态。优先局部测试，再在父任务最后的真实场景验证集成。
