# M07 · 工作流学习与功能生成

候选→复用检索→工程简报→草稿→验证→版本发布

## 模块内部结构

工程执行器产生候选，独立验证器检查，发布器切活动指针；三个职责分开。业务入口固定版本，产物和报告绑定哈希。

## 共享接口

- [C02 任务与产品 API](../contracts/C02.md)
- [C06 成果与存储](../contracts/C06.md)
- [C08 技能与独立验证](../contracts/C08.md)

## 责任边界

候选代码不得掌握评判器/发布器权限。未见输入的预期结果由验收方掌握；新权限不能继承旧授权。

归属范围：`services/control/capabilities`, `skills/templates`, `integrations/validation`。实际写权限进一步受单张任务卡限制。

## 输入输出与验收

把重复劳动变成经过验证、可再次使用的功能。

输入由契约和上游已验收产物提供；输出经本模块公开接口交给下游，不越层读取供应商内部状态。优先局部测试，再在父任务最后的真实场景验证集成。
