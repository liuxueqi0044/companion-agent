# M06 · 人格、长期记忆与工作记录

人格/策略→观察→串行写入→管理/删除→回归

## 模块内部结构

观察引用原任务证据；主控通过底座入口更新事实，产品保存来源索引。UI 经 API 查看和编辑，工作者只能建议。

## 共享接口

- [C07 记忆和工作记录](../contracts/C07.md)

## 责任边界

不能直接从多个进程改上游 SQLite；遗忘覆盖当前快照/检索来源，备份按已声明保留期处理。

归属范围：`adapters/hermes/memory`, `services/control/memory`。实际写权限进一步受单张任务卡限制。

## 输入输出与验收

记住人的偏好与纠正，让用户能理解和控制记忆。

输入由契约和上游已验收产物提供；输出经本模块公开接口交给下游，不越层读取供应商内部状态。优先局部测试，再在父任务最后的真实场景验证集成。
