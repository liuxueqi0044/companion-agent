架构版本 architecture-v3，更新于 2026-09-29。本文描述已经落地的源码；早期 architecture-v2.2 中“只完成 M01、等待下一步”的状态已经被后续完整实现替代。

**M01–M06 已完成设计与实现，M07 已完成本地验收与交付。** / 已切换到新版，/rebuild/ 指向同一页面用于验收，/legacy/ 保留旧版。

## 设计目标

普通访问者应直接看懂三个主张：助手能力可以组合、助手界面可以自由改变、创意可以与世界分享并成为作品。英文文案同时面向创作者与开发者，不以“无需编程”排斥开发者，不伪造用户数量、成交量或已上线的社区服务。

构图沿用 [用户参考图](references/approved-reference.png)，M01 的视觉开发材料保留在 [M01](artifacts/M01/)。首屏突出真实枝叶与纸张材质；中段展示大量不同界面；社区保持左侧文案、右侧作品和人物的空间关系。

## 实际技术方案

| 层 | 当前实现 |
| --- | --- |
| 首屏 | 写实图像分层；四张固定技能标签；Video Editing / Research 的原图精确裁片；局部 cleanplate 补底与绳索衔接 |
| 画廊 | Three.js 的四条流动画带；8 张独立近景素材和远景图集；指定卡片使用连续轨迹 |
| 社区 | 3 张主作品、5 位插画人物、约 20 张远景作品，以及植物、丝带和纸感布局 |
| 跨场景转场 | 一个 DOM 投影桥，接收场景的四角屏幕坐标；纸卡进入画廊，画廊作品进入社区 |
| 总调度 | GSAP 唯一时钟、ScrollTrigger 整体进度、Lenis 平滑滚动；场景不自行启动 RAF |
| 可访问性与回退 | 原生对话框、焦点恢复、暂停按钮、系统减少动态效果、完整静态章节、图片/WebGL 失败回退 |

首屏不是实时树木建模。当前没有接入 Blender 资产流水线、Bloom 后处理链或视频序列帧；写实图像与精确运动实现了这次已确定的构图。唯一 WebGL 渲染器由 GalleryHost 持有，场景之间不创建额外渲染器。

## 关键约束

场景把纸卡/作品的真实四角暴露给 TransitionLayer。转场期间由 handoffHiddenIds 隐藏原对象，桥负责可见副本，结束后交还目标场景。指定画廊卡片不使用会跳回起点的取模轨迹。

环境时间、指针、滚动进度分别输入场景。对话框打开或页面隐藏时暂停相应运动；固定 time 能复现构图。资源晚到时只在稳定章节启用跨场景交接，避免转场中途突然出现对象。WebGL 丢失或必需资源失败时撤销交接，使用完整回退画面。

移动端统一使用 <=680px，平板为 681–1023px，桌面为 >=1024px。DPR 仅影响渲染密度，场景锚点始终是 CSS 像素。

## 运行与交接

项目根目录使用 Node.js >=22.12.0：

~~~sh
npm ci
npm run dev
npm run check
npm run build
npm run preview
~~~

本地端口为 4332。/rebuild/?review=1 打开转场审看；?replay=A、?replay=B 可自动播放，追加 &reverse=1 可反向。更多定位入口见 [转场说明](TRANSITIONS.md)。

本项目提供营销前端和本地 JSON 草稿。账户、社区发布、支付交易、安装包分发和助手执行后端仍待接入。主作品按钮现在打开详情，不能据此声称交易能力已经上线。

素材清单记录的是文件字节与引用关系。首屏资源、首屏 HTML 回退图、全站可达资源分别统计；后续画廊和社区在首屏解码后加载，当前并非按滚动距离延迟加载。准确数字和许可来源以 [M07 资源记录](artifacts/M07/ASSETS-AND-LICENSES.md) 为准。旧方案中的候选库、候选作品及供应商不代表已经采购、授权或接入。
