## 已固化的决定

1. 首屏保留获选图的真实材质与构图。两张原图纸卡及绳索分离，补底限定在局部遮罩内，避免整屏 cleanplate 与母图不一致。质量不足的生成透明素材保留来源但未发布使用。
2. 新版不沿用旧程序化树和机械组装章节。新版运行结构与旧站保留结构分离。
3. 近景界面单独准备，社区三作品同时进入画廊，使用同一资源完成 B 交接。
4. 一个总时钟、一个 Three.js 渲染器、一个 DOM 桥；Frame / Fieldnotes 使用连续入口和闭合轨道。
5. 资源晚到不在普通转场中途开启桥；必需资源或 WebGL 失效撤销交接并回退。
6. 所有场景与桥共用 <=680px 移动端断点；移动端作品克隆继承当前比例和布局上下文。
7. 安装包、社区、支付和公开发布的后端未接入，页面明确状态；本地 JSON 下载不伪装成线上发布成功。
