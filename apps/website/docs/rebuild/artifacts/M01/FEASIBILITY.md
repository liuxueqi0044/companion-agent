# M01 — 材质与分层试样结论

本记录针对 M01 设计稿和试样，不是 M02/M03 生产资产验收。所有新增图像由内置 image_gen 以用户参考图约束生成；提示词保存在 source/，实际像素与哈希保存在 proof/asset-audit.json。

## 已用画面验证

- **枝叶与纸牌质感：**hero-art-v1 具有树皮裂纹、叶脉透光、前后景虚化、纸纤维、牌孔与挂绳阴影。material-study-v1 给出树皮、叶片、纸张三个近景材质目标。
- **首屏分层可行性：**hero-cleanplate-study-v1 移除 Video Editing 与 Research 两张牌，保留其余四张，补出遮挡下的枝叶。净底与原图同画幅，足以验证路线可实施；生产仍需在同一基准上精确对齐。
- **纸牌可独立运动：**tags-study-v1 提供两个透明牌面，可支持 M01 路径预演。其牌面形状与光照并非原图逐像素提取，透明边缘有白/黄色毛边，不能当成最终切图。
- **社区构图：**community-art-v1 包含三件主题作品、五位统一画风的插画人物、远景群、曲带与植物，能支持按参考制作完整右侧场景；它目前是一张设计母版，尚未获得全部独立生产层。
- **人物分层试样：**people-study-v1 为五位透明半身插画，已用于B预演验证各自入场；部分发丝边缘仍需清理，不能替代M03独立人物源文件。

## 下游必须完成

| 模块 | 制作任务 | 验证方式 |
| --- | --- | --- |
| M02 | 以本次评审后的首屏为同一基准，制作精确对齐的牌面/净底/挂绳/孔位/阴影；清理透明边缘 | 在原位置叠合/隐藏/移动，检查大小、亮度、遮挡和残影 |
| M02 | 英文技能文字与牌面几何一致；制作手机局部场景和必要前景层 | 实际浏览尺寸检查字形、裁切与可读性 |
| M03 | 从社区母版制作三件高清无字作品、五位透明人物、前后曲带、远景、植物与柔影 | 按相同坐标重组，应保留母版的密度和关系 |
| M03/M04 | 图廊与社区引用同一作品资产，标题与动作胶囊独立排版 | 连续交接检查作品身份、裁切与透视 |
| M04 | 24个现有概念的分级纹理，其中8个独立近景重制 | 不把约627px的图集单格无限放大 |
| M05 | 使用上述生产层实现正式动画，替换预演占位和示意层 | 实际滚动、反向、跳章及固定进度的连续性验收 |

图像路线已经有可见依据，暂不需要购买植物模型或强制制作实时树木。若 M02 的局部边缘、挂绳或视角仍不能达到要求，优先针对对应层重制；需要更强视角控制时再采用成熟植物模型离线渲染。M01 不承担完整实时场景与交易产品实现。

手机稿用于确定内容先后与主体占比，使用裁切美术底图表达方向；M02/M03 按其布局制作独立图层。运动预演用于检查对象路径、换面时点与社区落点，其中已标注的临时图形不代表最终材质。
