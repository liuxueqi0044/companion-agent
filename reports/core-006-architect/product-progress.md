# CORE-006 后的产品进度

2026-09-24。依据当前工作区源码、独立复核、本地回归与演示；不把历史 submitted、自测数量或任务编号当作产品完成百分比。

## 当前判断

已经从分散功能走到一个统一的可信运行时：调用者可以初始化个人空间、发送一条任务、看到实际任务和结果、操作记忆与消息，然后关闭并重开。这个入口以后可以接正式前端，前端不必自己拼接任务执行、消息更新和资源回收。

**以“少量用户可安装试用的桌面首版”为目标，工程估计约完成 50%–60%。** 这是按剩余工作量与集成风险作出的粗估，不是实测统计或交付时间承诺；真实模型与原生宿主尚未贯通，后续估计可能调整。本地内核的完成度明显高于实际用户体验。用户描述的完整 Personal AI 愿景还包括长期成长、可生成工具、自由改界面和分享生态，不宜套用这个百分比。

## 已有能力与真实边界

| 产品能力 | 当前达到的程度 | 距用户可用还缺什么 |
| --- | --- | --- |

| 对话与做事 | 统一 send 到受控执行；真实 Node→Python→SQLite→CSV 核对、来源结果、任务状态 | 真实模型语义决策和更多有用工具；目前不是通用电脑操作 |
| 主动联系 | 默认关闭；允许后有候选、到期重评估、send/defer/cancel、安静时段/限额、收件箱及事后解释 | 真实模型判断时机/措辞、后台唤醒、系统通知；现由可信宿主显式 pulse，尚非自主常驻 |
| 用户提醒 | 创建、修改、取消、到期投递，与 AI 自主问候区分 | 后台可靠执行及面向用户的入口 |

五份演示中的模型回复均为合成输入；真实数据库、子进程和 CSV 计算是实跑。不能用这些演示证明模型会自然理解需求、主动关心的质量或学习了用户习惯。历史 DeepSeek 试验也不等于当前内核完成真实模型接入。独立 core 工作区尚未与原 companion-agent 完成发布整合。

## 本批收益

CORE-006 将应用控制器、任务 runner、主动联系 runner 合成统一入口。发送、取消、读回、消息同步、关闭等待不再要求前端自行串接。本轮独立检查发现并修复四类边界问题，最终 Python 121 / Node 172、Schema、五份离线演示通过，补丁范围另行检查。

## 下一步建议

1. **优先做首个可亲自操作的产品流程。** 架构师制作温暖简洁的默认个人空间，将对话、较大的活动区域、记忆和近况接到当前运行时；开始视觉工作前先通知用户。先完成真实状态展示和完整错误/取消体验。
2. **在受控桌面宿主接通一个真实模型。** 经独立授权的凭据与请求额度，串行验证普通对话、记忆、一个真实任务及一条主动联系；不得沿用历史额度或触碰用户担心的账户。完成加载、断网、重开、退出的实用性验证。
3. **完成最有传播力的一条链。** 用户说“换一种界面”→代码生成→隔离预览→应用→恢复原版，并与同一个身份、记忆、任务状态相连；保留可信停止和恢复入口。
4. 首轮试用后，再扩充后台调度、原生通知、更多工具与分享。优先降低首次使用成本并证明日常价值，不继续无边界堆叠通用框架。

这份清单是下一阶段优先级建议，本次未派发新批次，也未启动视觉开发或真实模型请求。
